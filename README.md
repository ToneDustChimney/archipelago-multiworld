## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **100+ Games** | Supports Zelda, Metroid, Hollow Knight, Stardew Valley and many more |
| **Multiworld Co-op** | Items from your game appear in friends' games and vice versa |
| **Web Interface** | Browser-based tracker and spoiler log for every player's session |
| **Self-Hosted** | Run your own Archipelago server for full control over your sessions |
